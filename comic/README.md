# Слайды комикс-пролога

Оболочка (`shell.cpp`) ищет здесь ровно пять файлов:

```
comic/slide1.png … comic/slide5.png
```

- Формат: PNG (грузится через `stb_image`, RGBA). Прозрачность работает.
- Пропорции: кадр вписывается в рамку с сохранением пропорций и центрируется,
  поэтому подходит любой размер. Рамка при окне 1200x900 — примерно **1030x586**
  (соотношение ~16:9). Рисуй под 16:9, чтобы не оставалось широких полей.
- Разрешение: 1600x900 или 2048x1152 с запасом на большие окна.
- Если файла нет, слайд показывается как пустая рамка с надписью `PANEL PENDING`
  и одной только подписью — игра не падает и не жалуется.
- Подписи к кадрам живут в `shell.cpp` (`SLIDE_TEXT`), а не в файлах.

⚠️ Новые ассеты обязательно добавляются в `.github/workflows/build.yml` во все
три платформенных артефакта — иначе в релизе их не будет (см. master_prompt.md
§10.1(A), это уже ломало релиз с `timertia.png` и музыкой).
