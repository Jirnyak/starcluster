STARCLUSTER
===========

Космо-экономическая игра. Сборка от 2026-08-07, коммит 494c29e.

Все файлы лежат в одной папке намеренно: ассеты (timertia.png, music/, comic/)
общие для Windows и Linux и обязаны лежать рядом с исполняемым файлом.


КАК ЗАПУСТИТЬ
-------------

macOS (Apple Silicon)
  Открой Starcluster.dmg, перетащи Starcluster.app в Программы, запусти.
  Приложение подписано ad-hoc, поэтому при первом запуске macOS спросит
  подтверждение: правый клик по иконке -> «Открыть» -> «Открыть».
  Всё нужное (SDL2, музыка, комикс) уже внутри .app.

Windows (64-bit)
  Запусти starcluster.exe. Рядом с ним должны лежать все 12 DLL из этой папки
  (SDL2, SDL2_mixer и звуковые кодеки) — они уже здесь. Не переноси .exe
  отдельно от папки: без любой из DLL Windows не запустит игру вовсе.

Linux (64-bit)
  ./starcluster-linux
  Нужны системные библиотеки SDL2:
    Debian/Ubuntu:  sudo apt install libsdl2-2.0-0 libsdl2-mixer-2.0-0
    Fedora:         sudo dnf install SDL2 SDL2_mixer
    Arch:           sudo pacman -S sdl2 sdl2_mixer
  Если файл потерял бит исполнения: chmod +x starcluster-linux

Android (arm64) — ПРОВЕРКА КОНЦЕПЦИИ, читай раздел ниже
  starcluster-android-arm64.apk. Скопируй на телефон и открой; Android
  спросит разрешение на установку из этого источника. Ассеты внутри apk,
  игра распакует их при первом запуске. Ничего докладывать рядом не надо.


ANDROID: ЧТО ЭТО И ЧЕГО ЖДАТЬ
------------------------------

Это не порт, а первая рабочая сборка под телефон. Игра идёт целиком — мир,
экономика, локальный полёт, музыка, — но управление сделано самым дешёвым
способом: системной экранной клавиатурой. Она поднимается сама и занимает
примерно 40% экрана. Это и есть пульт.

Работает:
  * все буквенные и цифровые хоткеи, Enter и пробел;
  * полёт W/A/S/D/Q/E/R/F — тап даёт импульс на четверть секунды;
  * весь оконный интерфейс пальцем: касание работает как клик мыши;
  * звук.

Не работает — этих клавиш на экранной клавиатуре просто нет:
  * стрелки (панорама карты, выбор элемента);
  * F1, F2, F5, F9 — справка, выкуп лицензии, СОХРАНЕНИЕ и ЗАГРУЗКА;
  * скобки [ ], Shift (варп), Tab (следующий агент).
  ESC заменяет системная кнопка «назад».

Отдельно: сохраниться и загрузиться на телефоне НЕЛЬЗЯ — F5 и F9 недоступны.
Партия живёт, пока живёт приложение.

apk подписан отладочным ключом: это сборка для пробы, а не магазинная.
Нужны arm64 (все телефоны примерно с 2019 года) и Android 5.0 или новее.


УПРАВЛЕНИЕ
----------

  F1            карточка управления (полный список клавиш)
  L             локальный полёт внутри системы
  W/S           тяга,  A/D  рыскание,  R/F  тангаж,  Q/E  крен
  Shift         ускорение времени
  M             бур (в поясе астероидов)
  K             стыковка,  C  вид-карта,  L  выход из локального режима
  V             сводка Тимертии: совет по торговле. Просчёт жжёт топливо
                реактора — процент бункера за нажатие.

Язык интерфейса выбирается в меню и запоминается между запусками.


ЗАМЕЧАНИЯ
---------

* macOS-сборка собрана под Apple Silicon (arm64). На Intel-маках не пойдёт.
* Сейв лежит в пользовательской папке приложения, а не рядом с игрой.
* Android-сборка проверена на эмуляторе Pixel 5 (arm64): ~19 кадров/с на карте
  скопления, ~28 в локальном режиме. Эмулятор рисует программно, на живом
  телефоне должно быть быстрее.
